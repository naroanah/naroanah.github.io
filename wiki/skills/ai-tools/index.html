    AI 工具链与模型选型¶

    大模型与编程智能体（Agent）已经彻底改变了计算机学习与软件研发的工作流。选对“外壳工具（AI IDE / Harness）”与“底层大脑（模型）”，能将环境配置、原型搭建、代码重构和文献消化的效率提升数倍。

    AI IDE 与编程 Harness 生态¶

    传统 IDE 是辅助人类手写代码的编辑器，而 AI IDE / Harness 是将大模型嵌入代码库上下文、终端与文件系统中，使其能够自主读代码、改文件、跑测试、修 Bug 的工作环境。

    主流工具横向对比¶

    工具名称 出品方与形态 核心特点与适用体验 注意事项
    Cursor Anysphere（基于 VS Code 定制桌面端） 最早出圈的 AI IDE 标杆，补全、多文件编辑与配套生态完善，支持切换多家模型 订阅套餐单价偏高（2026 年起内置 Composer 与 Grok 模型性价比较高）
    GitHub Copilot GitHub / 微软（VS Code / JetBrains 插件） 与原生编辑器无缝集成，体验接近 Cursor，支持接入自定义第三方模型（如 DeepSeek） 补充 通过 GitHub Student Developer Pack 认证的在校大学生可免费申领教育版权益
    Claude Code Anthropic（CLI / 桌面端 / 网页 / IDE 插件） 社区口碑极高的编程 Agent，擅长长链路自主探索代码库、复杂重构与终端自动化执行 官方订阅与重度 Token 消耗成本昂贵
    Codex OpenAI（CLI / 桌面端 / IDE 插件） 定位与 Claude Code 对标的自主编程 Agent，与 GPT 系列模型深度协同 依赖网络环境与 OpenAI 账号体系
    opencode 开源社区（命令行 Agent） 完全开源，可自由配置并接入国内外任意兼容接口的大模型 API 纯终端交互为主，适合习惯命令行的开发者
    Trae / Workbuddy / Qoder 字节跳动 / 腾讯 / 阿里 交互形态与 Cursor 及桌面端 Agent 接近；普遍区分国内版（内置国产模型、网络直连）与海外版（支持海外模型） 免费额度较友好，但部分版本工程稳定性仍在迭代，偶有细节 Bug
    厂商原生工具（ZCode / Kimi Code 等） 智谱 / 月之暗面 / DeepSeek 等 与自家模型深度绑定、针对特定模型工具调用专门调优 若主力固定使用某一家国产模型，优先选用该厂商配套 Harness 往往表现更稳

    补充：什么是编程领域的 Harness？

    裸模型（LLM）本身只能“输入文本、输出文本”。Harness（套具/运行框架） 负责在模型外层提供：代码仓库索引与上下文裁剪、文件读写与局部补丁（Diff）工具、Shell 命令沙箱执行、Linter/编译器报错自动回传循环、以及危险命令权限拦截。因此，“编码体验 = 模型智商 × Harness 工程调优”——选工具壳与选底层模型应当分开考量。

    自定义 API 接入与选型原则¶

    • BYOK（自带 API Key）接入：绝大多数 AI 工具（如 Claude Code、opencode、Copilot 等）均支持配置自定义 Base URL 与 API Key。可参考 DeepSeek 官方 Claude Code 接入指南 或借助 cc-switch 等配置切换工具快速切换底层模型供应商。
    • 实操选型策略：AI 工具月月更新，不必陷入“哪家最强”的口水战——利用各家免费额度亲自试手一轮，挑最顺手的交互界面，再按任务难度动态切换高智商模型或高性价比模型。

    主流大模型分场景横评¶

    以下模型代数与梯队表现基于原文档记录节点（2026 年年中）；模型迭代极快，实际订阅或充值前可结合当期最新评测微调。

    场景一：网页端日常问答、课程辅导与文档写作¶

    模型系列 代表版本（2026 年中） 核心长板 短板与使用体验
    GPT（OpenAI） GPT-5.6 系列 综合全能标杆：联网搜索、多模态识图、绘图、Deep Research 与 Agent 能力均衡，适合日常答疑与学习辅导 免费额度满足轻度需求，重度使用需付费订阅
    Claude（Anthropic） Claude 5 系列（Opus 5 / Sonnet 5 / Fable 5） 长文本理解与自然文风公认最佳；Artifacts 实时渲染网页与图表极适合整理笔记与技术写作 国内网络访问门槛高，账号风控封禁严格
    Gemini（Google） Gemini 系列 + Nano Banana 多模态识图与图像生成表现亮眼，与 Google 生态及 NotebookLM 打通顺畅 纯复杂逻辑推理略逊于同代顶尖 GPT / Claude
    DeepSeek DeepSeek V4 系列 国产开源标杆，网页端免费、中文理解与数理推理扎实 官方网页端周边 Agent 附加功能较少，定位朴素
    Kimi（月之暗面） Kimi K3 评测指标位居前列，网页端 Agent 功能丰富，生成演示文稿（PPT）体验突出 高阶套餐与 API 定价偏贵
    GLM（智谱 Z.ai） GLM-5.2 编程与 Agent 工具调用能力强，网页端工作流完善 免费额度较少，高阶 Agent 能力需额外付费
    豆包（字节跳动） 豆包网页 / 客户端 国内日常交互体验流畅、免费功能极多，适合泛生活与轻量问答 不适合高严谨度的复杂数学推导与严肃科研论证
    MiniMax MiniMax M3 响应速度极快 模型体量较小，复杂推理易出错，网页端免费入口受限

    场景二：IDE / Harness 内工程编码与重构¶

    编码场景的核心权衡指标只有两个：复杂任务一次性成功率与 Token 成本。

    • 海外顶配梯队
    • Claude Code + Opus 5 / Fable 5：复杂跨文件重构与长时间自主 Agent 任务的口碑天花板，代码稳健度最高，唯一缺点是极其昂贵。
    • Codex + GPT-5.x（如 GPT-5.6-sol）：编码实力与 Claude 同处第一梯队，模型档位丰富，同价位套餐给的调用额度通常比 Claude 更充裕。
    • 国产主力与高性价比梯队
    • DeepSeek V4（含 V4-flash）：开源高性价比首选，常作为第三方 API 接入 Claude Code 或 Cursor 充当日常主力，编码体感优秀且单价低廉。
    • Kimi Code（K3） / ZCode（GLM-5.2）：国产第一梯队编码表现，逼近海外顶尖闭源模型，但重度使用价格偏高（K3 推理速度相对较慢）。
    • MiniMax Code（M3）：极快极便宜，适合简单样板代码补全，不建议独立承担核心生产逻辑编写。

    补充：Vibe Coding（AI 辅助编程）工程避坑四原则

    1. 先把需求边界写清楚：与人类协作一样，AI 写歪往往源于提示词缺少上下文（输入输出格式、技术栈约束、边界条件）。先让 AI 输出简要修改方案（Plan），确认无误后再让它改代码。
    2. 高频 Git Commit 存档：每当 AI 完成一个小功能且测试跑通后，立即 git commit；一旦下一步重构改崩，可随时一键 git restore 回退。
    3. 必须能读懂关键代码：对于课程设计、毕业设计与求职简历项目，务必搞懂核心模块的数据流与设计取舍——面试官深挖项目时，“这块是 AI 生成的我没细看”等于直接挂面。
    4. 用测试与编译结果闭环验证：不要轻信模型的口头承诺（“已修复所有问题”），要求它在终端实际跑通单元测试、类型检查或构建命令。
