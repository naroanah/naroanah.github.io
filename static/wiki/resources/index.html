    资源导航索引¶

    本页集中归档全站提及的优质公开课、刷题网站、工程文档、求职面经与科研检索入口，方便日常按图索骥。标注 补充 的条目为编者在原文推荐清单基础上增补的业界公认经典资源。

    核心自学导航站¶

    • CS 自学指南（csdiy.wiki）：开源中文计算机自学路线图圣经，按知识体系系统梳理了 MIT、CMU、UCB、Stanford 等世界顶尖名校公开课、配套实验（Lab）与先修依赖，是践行“自学能力”的最佳起点。

    算法刷题、求职面经与工程检索¶

    算法与竞赛平台¶

    • LeetCode（力扣）：研发求职必刷平台，优先攻克 Hot 100 与 面试经典 150 题单。
    • CodeTop：按各大厂、具体事业群与岗位实时统计近期面试高频手撕真题，考前突击利器。
    • 牛客网：校招笔试真题模拟（练习 ACM 标准输入输出模式）、面经交流与开奖薪资情报社区。
    • 洛谷 / Codeforces：面向蓝桥杯、ICPC / CCPC 算法竞赛选手的进阶题库与在线赛场。
    • Kaggle：全球最大数据科学与机器学习实战竞赛社区。

    求职八股与技术专题¶

    • JavaGuide：Java 后端生态、并发、JVM、分布式与常见中间件系统面试知识库。
    • 小林 coding：图解计算机网络、操作系统、MySQL 与 Redis，直观易懂，各语言开发岗通用。
    • 代码随想录（卡哥笔记）：结构化算法刷题顺序指南与配套基础八股梳理。
    • 竹子爱熊猫 MySQL 专题博客：深入浅出梳理 MySQL 架构、索引与事务锁机制。

    开发者社区、文档与 AI 接入¶

    • GitHub / Gitee：全球最大开源代码托管平台与国内镜像协作平台。
    • Stack Overflow：英文编程疑难杂症高质量问答库。
    • 《提问的智慧》（中科大 LUG 译本）：开源技术社区高效求助必读指南。
    • DeepSeek Agent / Claude Code 接入文档：将自定义模型 API 接入主流编程 Harness 的官方配置指南。
    • Google NotebookLM：导入课程讲义、教材与论文 PDF 进行基于源材料的无幻觉问答与复习总结。
    • Missing Semester（MIT 计算机教育中缺失的一课） 补充：专门讲授 Shell、Vim、Git、SSH、命令行环境与调试剖析的开源短课，完美对应第三章工程工具链。

    科研与升学信息渠道¶

    • CCF 推荐国际学术会议和期刊目录速查（ccf.atom.im）：快速检索计算机各子领域会议/期刊的 CCF A/B/C 等级与截稿日期。
    • Google Scholar（谷歌学术） & Zotero：学术文献检索标准入口与免费开源跨平台文献管理工具。
    • arXiv / Connected Papers / CSRankings 补充：最新预印本追踪、文献引用关系图谱可视化、以及全球高校计算机细分方向师资实力检索。
    • 计算机保研全流程经验指南（知乎专栏）：夏令营、预推免材料准备与考核全流程参考。
    • 一亩三分地论坛：海外 CS 硕士/博士选校定位、录取汇报、海外求职与签证高频信息社区。
